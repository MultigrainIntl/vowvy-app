# VOWVY regression foundation

`npm test` protects deterministic location hierarchy, health checks, and onboarding templates.

`npm run test:browser` checks the rendered public authentication path on desktop and mobile Chromium: landing navigation, registration gating, policy links, password visibility, reset messaging, and English/Spanish switching.

`npm run qa` runs unit tests, browser tests, TypeScript validation, and the production build.

Authenticated Firebase workflows are intentionally not faked here. Gate 4 must add controlled test-user and test-data coverage for locations, containers, photos, AI/search, QR, trash/restore, collaborators, Manage Locations, and listing drafts.
